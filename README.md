# SHK Störungs-Quiz

Mobile-first Quiz-Variante des SHK Diagnose Simulators.

- 10 Störungsfragen
- 4 Antwortmöglichkeiten
- genau eine richtige Antwort
- 30 Sekunden pro Frage
- Punkte + Zeitbonus + Serienbonus
- sofortige fachliche Erklärung
- PWA für iPhone/Android

Für iPhone: Dateien auf einen Webserver/GitHub Pages hochladen, `index.html` öffnen und in Safari „Zum Home-Bildschirm“ wählen.
